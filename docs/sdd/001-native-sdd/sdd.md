# 001 — Native SDD

## Why

The repository authors its own contracts with an external tool (OpenSpec),
adopted in commit `86f6ba8` with no ADR — the only structural decision in the
repo without a record. Two symptoms: `PLANO.md:152-169` describes the repo
structure and does not list `openspec/`; `PLANO.md:83` points phase T's plan
into `openspec/changes/archive/`, the only phase whose plan does not live in
`docs/relatorios/`.

What was lost with jacu-code was never OpenSpec. It was the rite of
`.jacu/specs/<NNN>-<slug>/sdd.md`: branch in the header, locked decisions, out
of scope, tasks `T1..Tn` with a **Verify** column as the definition of done,
pasted evidence, `NEEDS-ERICK` human gates. That contract is transcribed in full
at `docs/heranca/09-specs-logica.md:778-797` and accepted at
`PLANO-ALVO.md:272` — with no owner and no phase.

This change gives it an owner, a phase, and a gate, and removes the external
dependency.

## Locked decisions

1. The binary **never authors prose**. Authoring requires a model; jacu does
   not call models. The binary parses, identifies, lints, and gates. — ADR-019
2. **One lint**, typed finding `{code, severity, target, message}`. Severity
   reuses the existing `BLOCK | WARN | INFO` vocabulary, and `blocked` coincides
   with the presence of a BLOCK, exactly as in `jacu_mission_compile`. — ADR-019
3. **Zero new MCP tools.** The capability is reached through `jacu sdd …`,
   authorized in `.jacu/verify-allowlist.json`. Surface stays at 13 tools and
   the `tools/list` ratchet stays at 20 KiB. — ADR-008, ADR-019
4. **English** for every agent-facing text. — ADR-019
5. **ADRs stay in `docs/adr/`.** `sdd.md` links, never restates. A second ADR
   home would repeat the four-lints mistake. — ADR-019
6. Requirement deltas are `ADDED | MODIFIED | REMOVED`, and a delta only
   **narrows** write scope, never widens it. — ADR-019
7. **One scope-conflict function** for the whole binary, shared by this lint,
   the scheduler, and the write-scope gate. Three answers to the same question
   means the product lies. — `docs/heranca/01-sdd.md:991`
8. No finding logic depends on message substrings. Message is text; `code` is
   the contract. — `docs/heranca/01-sdd.md:1003`

## Out of scope

Forbidden during execution. If the executor believes one is necessary, it stops
and reports.

- Generating, suggesting, or summarizing spec prose.
- Emitting telemetry events. SDD-002 wires `sdd.*` events; instrumenting a
  module before the schema exists creates dead fields.
- `jacu sdd close` and any clean-exit checking. That is SDD-003.
- The clarity gate, the pre-flight, the context ledger.
- Any new MCP tool, HTTP endpoint, or viewer.
- Changing `jacu_mission_compile` behavior.
- Deleting anything outside `openspec/` and `.claude/` (see task T26 for the
  exact set).

## Requirements

### Requirement: Canonical SDD layout

The repository SHALL store each change as a single directory
`docs/sdd/<NNN>-<slug>/` containing `sdd.md` (hand-authored) and
`sdd.lock.json` (generated). Living capability specs SHALL live at
`docs/sdd/specs/<capability>/spec.md`, closed changes at
`docs/sdd/archive/<YYYY-MM-DD>-<slug>/`, and conventions at
`docs/sdd/CONVENTIONS.md`.

Delta: ADDED

#### Scenario: A new change is scaffolded

- **WHEN** `jacu sdd new "<slug>"` runs in the project root
- **THEN** `docs/sdd/<NNN>-<slug>/sdd.md` is created from the template with the
  next free three-digit number, and no other file is written

#### Scenario: A malformed directory is refused

- **WHEN** a directory under `docs/sdd/` does not match `<NNN>-<slug>`
- **THEN** `jacu sdd lint --all` reports BLOCK `sdd_bad_directory` and exits 1

### Requirement: Deterministic SDD identity

The `sdd_id` SHALL be `"sdd_"` followed by the lowercase hex encoding of the
first 8 bytes of the SHA-256 digest of the JSON encoding of the normalized
document, using the same construction as `mission_id`. Normalization SHALL trim
whitespace, remove duplicates, and sort lists lexicographically. Inputs
differing only in whitespace, list ordering, or duplicate entries SHALL produce
the same id; different content SHALL produce a different id.

Delta: ADDED

#### Scenario: Whitespace does not change identity

- **WHEN** the same document is linted with trailing spaces added to list items
- **THEN** `sdd_id` is unchanged

#### Scenario: Content changes identity

- **WHEN** a requirement's normative sentence changes by one word
- **THEN** `sdd_id` changes

### Requirement: Single typed lint

`jacu sdd lint` SHALL produce findings as `{code, severity, target,
message}` with severity in `BLOCK | WARN | INFO`. Exit code SHALL be 0 with no
BLOCK, 1 with any BLOCK, and 2 on invalid usage. The presence of a BLOCK finding
and a non-zero lint exit SHALL always coincide. No control flow SHALL branch on
message text.

BLOCK codes: `sdd_bad_directory`, `sdd_missing_section`, `sdd_task_without_verify`,
`sdd_task_done_without_evidence`, `sdd_two_tasks_in_flight`,
`sdd_out_of_scope_touched`, `sdd_stale_lock`, `sdd_open_decision`.

WARN codes: `sdd_requirement_without_scenario`, `sdd_locked_decision_without_adr`,
`sdd_task_without_red`, `sdd_language_not_english`.

INFO codes: `sdd_delta_summary`.

Delta: ADDED

#### Scenario: A task row without Verify blocks

- **WHEN** a task table row has an empty Verify cell
- **THEN** lint reports BLOCK `sdd_task_without_verify` targeting that row and exits 1

#### Scenario: Done without evidence blocks

- **WHEN** a task row has status `done` and an empty Evidence cell
- **THEN** lint reports BLOCK `sdd_task_done_without_evidence` and exits 1

#### Scenario: Two tasks in flight block

- **WHEN** two task rows have status `doing`
- **THEN** lint reports BLOCK `sdd_two_tasks_in_flight` and exits 1

#### Scenario: A requirement without a scenario warns

- **WHEN** a `### Requirement:` block contains no `#### Scenario:`
- **THEN** lint reports WARN `sdd_requirement_without_scenario` and exits 0

#### Scenario: The language heuristic never blocks

- **WHEN** the document contains Portuguese stopwords above the threshold
- **THEN** lint reports WARN `sdd_language_not_english` and exits 0

#### Scenario: A well-formed document is silent

- **WHEN** a document has every required section, scenarios on every requirement,
  Verify on every task, and a fresh lock
- **THEN** lint reports no BLOCK and no WARN and exits 0

### Requirement: Lock file detects drift

`jacu sdd lint` SHALL compare the SHA-256 of the normalized document against
`sdd.lock.json`. A mismatch SHALL be BLOCK `sdd_stale_lock`. `jacu sdd
lint --write-lock` SHALL regenerate the lock. The lock SHALL contain `sdd_id`,
`content_sha256`, `requirements` with their deltas, and `tasks` with their
declared Verify commands — no prose.

Delta: ADDED

#### Scenario: Editing the document without relocking blocks

- **WHEN** `sdd.md` changes and the lock is not regenerated
- **THEN** lint reports BLOCK `sdd_stale_lock` and exits 1

### Requirement: Out-of-scope enforcement shares one scope function

The lint SHALL determine whether a changed path falls outside the document's
declared write scope using the **same** scope-conflict function the workspace
write-scope gate uses. The function SHALL live in exactly one package and be
consumed by both.

Delta: ADDED

#### Scenario: A path outside the allowed scope blocks

- **WHEN** the working tree contains a change under a path not covered by
  `Write scope / Allowed`
- **THEN** lint reports BLOCK `sdd_out_of_scope_touched` and exits 1

#### Scenario: Both consumers agree

- **WHEN** the same pair of path sets is evaluated by the lint and by the
  write-scope gate
- **THEN** both return the same verdict

### Requirement: Parser is total

Parsing SHALL never panic on any input. Any byte sequence SHALL produce either a
parsed document or findings, including empty files, binary content, unbalanced
headings, and 1 MiB of a single line.

Delta: ADDED

#### Scenario: Arbitrary input does not panic

- **WHEN** the fuzz corpus of arbitrary markdown is parsed
- **THEN** no input panics and every input yields findings or a document

### Requirement: CLI contract

`jacu sdd` SHALL expose `new`, `lint`, and `status`. `lint` SHALL accept a
directory or `--all`, and `--json` SHALL emit the finding list as JSON on
stdout. All diagnostics SHALL go to stderr. `status` SHALL print the derived
task state — computed from the lock, the working tree, and run state — never the
hand-written checkboxes.

Delta: ADDED

#### Scenario: JSON output is machine-readable on stdout

- **WHEN** `jacu sdd lint docs/sdd/001-native-sdd --json` runs
- **THEN** stdout contains only the JSON finding array and diagnostics go to stderr

#### Scenario: Invalid usage exits 2

- **WHEN** `jacu sdd lint --nonsense` runs
- **THEN** the process exits 2 and prints usage to stderr

### Requirement: Host reaches the lint without a new tool

`.jacu/verify-allowlist.json` SHALL authorize program `jacu` with
`required_arg_prefix: ["sdd"]`. The MCP surface SHALL remain exactly 13 tools
and `tools/list` SHALL remain within the 20 KiB ratchet.

Delta: ADDED

#### Scenario: The lint runs through jacu_verify

- **WHEN** `jacu_verify` is called with argv `["jacu","sdd","lint","--all"]`
- **THEN** it returns a verdict rather than an allowlist denial

#### Scenario: The surface is unchanged

- **WHEN** the e2e suite lists tools
- **THEN** exactly the 13 expected tools are returned and the catalogue is under
  the ratchet

### Requirement: Skill ships with the capability

`skills/jacu-sdd/SKILL.md` SHALL exist, be written in English, stay under 100
lines of body, cover only this capability, and carry a frontmatter description
with concrete triggers disjoint from its siblings. `skills/using-jacu/SKILL.md`
SHALL gain one route and stay under 40 lines.

Delta: ADDED

#### Scenario: The skills check passes

- **WHEN** `go test ./internal/mcpadapter -run Skills` runs
- **THEN** it passes with the new skill and the updated router

### Requirement: OpenSpec is removed

`openspec/specs/` SHALL move to `docs/sdd/specs/`, `openspec/changes/archive/`
to `docs/sdd/archive/`, and `openspec/config.yaml`, `.claude/skills/openspec-*`,
and `.claude/commands/opsx/` SHALL be removed. After the move,
`jacu sdd lint --all` SHALL pass over the migrated corpus.

Delta: ADDED

#### Scenario: No OpenSpec references remain outside history

- **WHEN** `grep -rn openspec . --exclude-dir=.git` runs
- **THEN** matches appear only under `docs/heranca/` and `docs/adr/`

#### Scenario: The migrated corpus is clean

- **THEN** it exits 0
