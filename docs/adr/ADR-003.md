# ADR-003: MCP versions and capabilities

- Status: accepted
- Date: 2026-07-30
- Decider: Erick

## Context

The server must follow the stable MCP specification without implementing
protocol or compatibility by hand. Hosts may still negotiate the previous
version.

## Decision

Use MCP spec 2026-07-28 as the default and keep backward compatibility with
2025-11-25 through negotiation in `github.com/modelcontextprotocol/go-sdk`.
New resources may be used only after capability negotiation. Roots, Sampling
and Logging MCP are forbidden because they are deprecated in spec 2026-07-28.

## Consequences

- The official SDK drives protocol negotiation and compatibility.
- The server does not assume host support for new resources.
- Roots, Sampling and Logging MCP are not implemented.
