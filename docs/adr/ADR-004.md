# ADR-004: STDIO transport

- Status: accepted
- Date: 2026-07-30
- Decider: Erick

## Context

JACU is a local server for coding agents. The current phase has not shown a
need for network exposure or an HTTP lifecycle.

## Decision

STDIO is the default transport. Adding HTTP requires a proven need and its own
ADR.

## Consequences

- The process integrates with local hosts over stdin/stdout.
- There is no HTTP server, port or network configuration in this architecture.
- A later HTTP adoption cannot happen without a recorded decision.
