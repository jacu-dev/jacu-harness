# ADR-002: MCP as an adapter

- Status: accepted
- Date: 2026-07-30
- Decider: Erick

## Context

The MCP protocol changes and must not define domain rules or capability
governance. The protocol boundary must stay replaceable and isolated.

## Decision

MCP is an adapter in `internal/mcpadapter`. That package translates protocol to
the runtime and never contains domain logic.

## Consequences

- SDK types and protocol details stay at the MCP boundary.
- Policy, control and execution belong to the runtime or the capability.
- Protocol changes do not change domain rules.
