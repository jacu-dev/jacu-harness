# ADR-005: Mandatory capability runtime

- Status: accepted
- Date: 2026-07-30
- Decider: Erick

## Context

Tools must apply the same validation, governance, execution control, output
and audit steps. Per-tool shortcuts would create paths without uniform
enforcement.

## Decision

Every tool must go through the runtime pipeline:
decode → schema → policy → control → execute → output → audit.
Every capability must declare a `ToolSpec`.

## Consequences

- There is no shortcut from the MCP boundary to execution.
- Policy, controls, output and audit follow a common order.
- A tool without a `ToolSpec` cannot be registered in the runtime.
