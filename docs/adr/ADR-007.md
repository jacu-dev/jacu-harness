# ADR-007: Trunk-based integration with human tag promotion

- Status: accepted
- Date: 2026-08-11
- Updated: 2026-08-18 (harness carve-out)
- Decider: Erick

## Context

Required GitHub status checks are a hard gate only on pull-request merge.
Direct pushes to `main` are not blocked by a red CI. With no human reviewer on
the default path, CI must be blocking, so the path into `main` is a pull
request without a required human reviewer.

The human gesture that publishes is moving the production tag, not approving
every pull request.

## Decision

1. **`main` is the machine integration line.** Work happens on short branches.
   Pull requests use auto-merge. **Zero required reviewers**, except the
   harness carve-out (2026-08-18). Required status checks are the only gate.
   Green CI merges automatically when the pull request does not touch the
   harness. Red CI or a review comment: the executor fixes and re-pushes.
2. **Production promotion is a tag, and only the owner.** Tag ruleset for
   `v*`/`prod`: restrict create/update/delete with owner-only bypass; signed
   tags required. The machine cannot create or move the tag.
3. **Publication fires on the tag.** The release pipeline consumes the tag.
   An optional publish job may use a `production` environment with the owner
   as required reviewer.
4. **The assertion "main never receives a machine commit" is revoked.** What
   the machine cannot touch is the production tag. Integration is `main`
   itself.
5. **Phase close** is a green technical gate (CI + evals + behaviour checks)
   plus auto-merge. Owner attention moves to owner-present evals and tag
   promotion.
6. **Integration uses squash.** Each merged pull request is one commit on the
   main line so `git log --first-parent` stays a readable sequence of pull
   requests.

Required repository settings: `main` requires a pull request, the full check
suite, zero approvals, `require_code_owner_review` on, no force-push.
CODEOWNERS covers only the harness. Tag ruleset `v*` is owner-only and signed.
Auto-merge is enabled; short branches delete on merge.

## Harness carve-out (2026-08-18)

Zero reviewers on every pull request would let an agent edit `.github/`,
`scripts/`, lint and the allowlist and merge on green CI — the theatre the
gate exists to prevent.

Integration autonomy remains: pull requests that do not touch the harness keep
zero approvals and auto-merge. Pull requests that touch paths in
`.github/CODEOWNERS` require `@ecouto` via `require_code_owner_review`.

This is not SDD-010 (`.jacu/protected.json`). CODEOWNERS is GitHub enforcement
outside the kernel. SDD-010 still queues JACU refusing the path in the
worktree.

## Consequences

- `main` is the private validation line; rollback is revert.
- Human diff review dies for ordinary changes without losing publication
  control: validate on `main`, then sign the tag.
- Harness diffs (CI, scripts, lint, AGENTS, allowlist) still need owner review.
