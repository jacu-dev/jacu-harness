# ADR-001: Go and a modular monolith

- Status: accepted
- Date: 2026-07-30
- Decider: Erick

## Context

JACU must be a small local process that compiles and ships as one unit. The
architecture separates the MCP boundary, the governance runtime and the
capabilities without premature extra modules or processes.

## Decision

Use Go in a modular monolith: one binary and one `go.mod`. Organize the system
as `internal/mcpadapter`, `internal/runtime` and vertical capability slices.

The original `go 1.26.x` floor is superseded for the public tree by ADR-028:
`go 1.25.0` with no toolchain pin.

## Consequences

- Build, test and distribution have a single unit.
- Internal boundaries are packages, not separate services or Go modules.
- A later split requires a new architectural decision.
