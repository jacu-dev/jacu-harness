# ADR-006: Deny-by-default security

- Status: accepted
- Date: 2026-07-30
- Decider: Erick

## Context

MCP annotations and skills are cooperative metadata, not a security boundary.
A generic shell tool would bypass command, argument, environment and workspace
controls.

## Decision

Apply deny-by-default. There will be no generic shell. Enforcement happens in
the runtime, never in an annotation or skill.

## Consequences

- Paths, commands, environment and network need explicit permission.
- Every capability is rejected when a required rule is undeclared.
- Annotations and skills may describe behaviour; they do not authorize it.
